# Day 15 – Product Count Analysis

## Objective
To analyze the distribution of records across different categories and sub-categories using Microsoft Excel.

## Tools Used
- Microsoft Excel
- COUNTIF
- PivotTable
- Charts

## Analysis Performed
- Category-wise record count
- Sub-category-wise record count
- Identification of the highest-count category
- Identification of the highest-count sub-category
- Summary of key findings

## Conclusion
The analysis provided insights into the distribution of records across different categories and sub-categories using Excel data analysis techniques.
